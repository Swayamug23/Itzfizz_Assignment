# Itz Fizz — Scroll-Driven Hero

A responsive landing-page assignment built with Next.js App Router, React, Tailwind CSS v4, GSAP, and ScrollTrigger.

## Features

- Full-screen hero inspired by the supplied Itz Fizz reference
- Staggered headline and statistic intro animation
- Scroll-scrubbed car movement, rotation, and scale
- Orbit accents tied to scroll progress
- Custom local SVG illustration (no external image dependency)
- Responsive desktop/mobile styling and reduced-motion consideration

## Requirements

- Node.js 20.9 or later
- npm

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production check

```bash
npm run build
npm start
```

## Push to GitHub

Create an empty repository on GitHub, then run these commands from this project folder (replace `YOUR_USERNAME` and `YOUR_REPO`):

```bash
git init
git add .
git commit -m "Build Itz Fizz scroll-driven hero"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

## Deploy on Vercel

1. Sign in at https://vercel.com and choose **Add New → Project**.
2. Import the GitHub repository you just pushed.
3. Keep the detected Next.js settings and click **Deploy**.
4. After deployment, copy the production URL from the Vercel project overview.

The public URL and GitHub URL are generated by your accounts after you complete these steps; they are not pre-created by this source package.
